MISTRZOSTWA MANAGER — GitHub Pages

Funkcje w tej pierwszej wersji:
- tworzenie turnieju świata, Europy lub własnego;
- wybór 8/16/24/32/48 uczestników;
- wybór reprezentacji z listy lub dodawanie własnych;
- losowanie grup i terminarza;
- wpisywanie wyników meczów grupowych oraz automatyczne tabele;
- tryb pucharowy z losowaniem par;
- zapis lokalny w przeglądarce oraz eksport aktualnego turnieju do JSON.

Publikacja:
1. Utwórz osobne repozytorium GitHub, np. mistrzostwa-manager.
2. Wgraj wszystkie pliki do głównego katalogu i kliknij Commit changes.
3. Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Otwórz adres pokazany przez GitHub Pages w Safari.
5. Safari → Udostępnij → Dodaj do ekranu początkowego.

Uwaga: to prototyp pierwszej wersji. Zapis jest lokalny dla tej przeglądarki/urządzenia. W trybie grupowym obecna wersja generuje grupy, terminarz i tabele; pełna automatyczna drabinka z awansującymi zespołami wymaga dalszego rozbudowania.
